# Verification

Install `requirements.txt` in a Python 3.11+ virtual environment. Icarus Verilog
and make must be on PATH.

- `make -C test`: public TinyTapeout pin tests for the configuration in `src/config.vh`.
- `python3 scripts/regress.py`: all ten parameter sets, PE + array + host stages.
- `python3 scripts/regress.py default rectangular`: selected sets.
- `make -C test GATES=yes`: official gate-level netlist (requires PDK_ROOT and
  `test/gate_level_netlist.v` from the matching physical build).

Run these commands from the repository root. Each sweep configuration has an
isolated build directory, XML result, and log under `test/sim_build`. The runner
checks both process exit status and XML failures. Seeds are fixed for reproducible
failures. Waveforms are generated by the host testbench at `test/tb.fst`.

The NumPy reference uses Python integer objects and explicitly wraps ACC_W bits,
so host integer overflow cannot hide hardware bugs. Pin tests use only public
ports and allow cell delays on both sides of each rising edge. Unit tests prove
the wavefront timing independently of the controller and check stalls/valid bits.
